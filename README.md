# Stick: Habit Checklist

A simple habit tracker built around a one-tap daily checklist (skincare, pills, …).

- **Live app:** https://lozanphir-bit.github.io/Test-/app/ (open in Safari → Share → Add to Home Screen)
- **Run locally:** serve the `app/` folder (e.g. `cd app && python3 -m http.server`) and open
  `http://localhost:8000`. On a phone, use "Add to Home Screen".
- **Compact checklist:** `index.html?view=widget`
- **Design, widget plan and roadmap:** see [DESIGN.md](DESIGN.md)
